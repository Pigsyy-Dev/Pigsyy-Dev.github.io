MARKDOWN  →  LATEX

让表格转换，简单又漂亮。

粘贴 Markdown 表格，即刻生成带完整边框的 LaTeX array 代码。支持中文、数学公式及混合内容。

Markdown 输入
粘贴或编辑你的原始表格
等待输入支持 $...$ 和 \(...\)
LaTeX 输出
实时生成 array 表格代码
等待转换Ctrl / ⌘ + Enter 复制
转换选项
默认所有列居中：{|c|c|...|}
使用提示：输出默认只包含 \begin{array} ... \end{array}，请将其放在 LaTeX 数学环境中；也可打开上方开关，自动添加 \[ ... \]。中文建议使用 XeLaTeX + ctex，并加载 amsmath 以支持 \text{...}。
